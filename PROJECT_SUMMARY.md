# Smart Pantry Manager Project Summary

## Application

Smart Pantry Manager is a Java Android application developed for Mobile App Development 700.

The purpose of the application is to help users manage the ingredients available in their pantry and identify recipes that can be prepared using those ingredients.

## Main Functionality

The application allows users to:

* Add ingredients
* View ingredients
* Edit ingredients
* Delete ingredients
* Search pantry ingredients
* Filter ingredients by category
* View suggested recipes
* View recipe details
* Access the Settings screen

## Database

SQLite is used for local data storage.

The database stores pantry ingredients, recipes and recipe ingredients.

The application contains a preloaded collection of 20 recipes.

## Recipe Matching

The application uses strict recipe matching.

A recipe is only displayed when every required ingredient is available in the pantry in a sufficient quantity.

Recipes with missing ingredients or insufficient quantities are excluded from the main suggestions.

## Technologies

* Java
