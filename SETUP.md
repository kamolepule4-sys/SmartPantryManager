# Smart Pantry Manager Setup Guide

## Requirements

To run the Smart Pantry Manager application, the following are required:

* Android Studio
* Android SDK
* Java
* An Android device or Android emulator

## Opening the Project

1. Clone or download the Smart Pantry Manager repository from GitHub.
2. Open Android Studio.
3. Select the project folder.
4. Allow Android Studio to complete the Gradle sync.

## Running the Application

1. Connect an Android device with USB debugging enabled, or start an Android emulator.
2. Select the device in Android Studio.
3. Click the Run button.
4. Android Studio will build and install the application on the selected device.

## Database

The application uses SQLite for local data storage.

The database is created automatically when the application runs.

The application also seeds the recipe collection when required.

## Using the Application

After starting the application:

1. Open the Pantry section.
2. Add ingredients using the Add Ingredient option.
3. View, edit or delete ingredients from the pantry list.
4. Open Suggested Recipes to see recipes that can be made with the available ingredients.
5. Select a recipe to view its ingredients and preparation steps.
6. Use the Settings screen when required.
